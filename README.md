# Closet 灵感采集 Chrome 扩展（1.4.6）

支持小红书单图/完整图集/视频、抖音网页版视频详情/推荐流及微信公众号文章/图文中的单图与完整图集。采集作者、标题、正文和媒体后创建素材并自动发布。

## 安装和连接

1. 在消费站衣橱首页“任务中心”右侧点击“下载采集插件”，解压 ZIP。
2. 打开 Chrome 扩展管理页，启用开发者模式，“加载已解压的扩展程序”，选择解压后的 `closet-collector` 目录。升级时替换原目录并在扩展管理页点击刷新。
3. 在同一 Chrome 浏览器登录 Closet4U 消费站，并保持至少一个消费站标签页打开。
4. 点击扩展图标，自动连接登录账号。默认地址为 `https://closet.cuddlycuddle.com`，也会自动尝试 `https://danime.dawoai.com/closet`。其他部署可以填写完整服务地址（支持 `/closet` 路径前缀）。无需手动输入密钥。
5. 刷新目标网页，将鼠标移到图片或视频上：
   - 小红书：打开笔记详情，单图点击“采集到Closet”，整组点击“采集全部图片”，视频点击“采集视频到Closet”。
   - 抖音：打开推荐视频流、`/video/视频ID` 详情或带 `modal_id` 的视频弹层，播放后点击“采集视频到Closet”。优先使用网页当前视频直链，读不到时由素材管理现有解析器尝试解析；仅采集能与当前播放器明确对应的作品，不猜测全局推荐列表的第一条。
   - 微信公众号：在 Chrome 打开 `mp.weixin.qq.com/s/...` 或带 `__biz/mid/idx/sn` 的文章，移动到正文图片上采集单图或整组。保留正文图片顺序，支持 `data-src` 懒加载和图片页图集数据；公众号视频和视频号不在此版本范围内。

升级至 1.4.0 后需在 Chrome 扩展管理页刷新扩展，并刷新已打开的目标网页。版本要求 Chrome 120+，新增 `alarms`、`notifications` 权限；系统通知需允许 Chrome 显示通知。

配置页面只显示自动获取的凭据，不能手工填写。凭据 15 分钟有效，扩展会通过已登录的消费站标签页自动刷新；原登录会话退出或失效后，凭据立即失效。没有打开消费站标签页时，点击“打开消费站登录”，登录后再点击连接。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `manifest.json` | 扩展清单（Manifest V3，要求 Chrome 120+） |
| `background.js` | Service Worker：凭据获取、采集提交、状态轮询、消息路由 |
| `content.js` | 页面内采集按钮注入与提取调度 |
| `extractors.js` | 小红书 / 抖音 / 微信公众号的元数据与媒体提取 |
| `task-tracker.js` | 任务持久化、状态检查、工具栏角标 |
| `history-ui.js` | 最近任务与历史记录面板 |
| `options.html` / `options.js` | 扩展弹窗与配置页 |
| `icons/` | 16 / 32 / 48 / 128 图标 |
| `test-*.cjs` | 测试脚本（3 个零依赖，2 个需 Playwright） |
| `package.json` | 仅用于测试脚本的 devDependency 与快捷命令，扩展加载本身不依赖 npm |

## 服务端与安全

链路为 Chrome 扩展 → 消费站后端 → 素材处理服务。消费站负责登录鉴权、签发仅限采集的短期用户凭据、验证原登录会话仍有效，以及任务查询的用户权限；素材处理服务负责下载媒体、创建素材和自动发布。

服务之间的转发使用独立的服务间密钥，该密钥不下发给扩展，也不出现在扩展的任何存储中。扩展只持有消费站签发的、仅限采集用途的用户凭据，该凭据 15 分钟有效并自动刷新。

凭据仅保存在扩展可信上下文存储中；扩展使用隔离脚本从消费站同源页面请求凭据，不读取登录 Cookie，不向小红书页面注入凭据。该凭据不具备通用账号 API 权限。扩展的采集按钮直接授权创建素材并提交自动发布任务。

## 重复采集和个人排序

消费站先查询已发布的公共原笔记。若已存在，直接复用，不请求素材管理服务，不创建素材或发布任务；只有未完成发布的笔记才进入后端采集/重试。已有完整笔记时，单图采集也复用完整笔记。

每次采集请求被接受后，消费站为当前登录用户建立或更新该博主的“搜过”关系，并记录个人采集时间。采集过的博主优先于普通关注/热度顺序展示；最近一次采集的笔记在本人的更新列表置顶（即使笔记较旧或已看过）。其余排序继续沿用原规则，不改变公共发布时间或其他用户的顺序。进行中的新笔记在发布完成后显示。

扩展会通知已打开的消费站标签页刷新博主和更新列表；网站原有博主筛选仍然有效。发布任务未完成时，扩展显示“正在自动发布”，完成后再刷新。

## 媒体和状态

通过当前 URL 对应的 `__INITIAL_STATE__.note.noteDetailMap` 读取完整图集或视频流，避免将评论、头像或推荐内容混入。视频流支持现有素材管理流程的 h264/h265/h266/av1 及 EF 编码键。后端只接收经校验的小红书 HTTPS CDN 地址，并清除其他视频流属性。

图片按既有流程转 PNG、最大宽度 1080；视频按既有流程下载原视频、抽帧、建立素材并发布。单图使用稳定独立素材 ID，图集和视频使用原笔记 ID。重复采集复用素材，发布入队失败可重试。来源链接保留原笔记地址。

发布排队时页面显示“正在自动发布”，发布完成后再显示成功并刷新消费站。失败原因在页面显示，也可在素材管理任务中心查看。采集排队状态保存在素材管理进程内，服务重启后需重新采集；已完成素材和发布任务仍由既有系统持久化。素材管理采集接口必须固定到同一个服务进程。页面关闭不取消后端采集。扩展持久保存已提交任务记录，关闭采集页或 Chrome 重启后会恢复查询；后端服务重启或任务查询过期时需重新采集，已创建素材和发布结果仍持久保存。

## 验证

本仓库内测试分两档。第一档为零依赖脚本，直接运行：

```sh
npm test          # 等价于下面三条
node test-background.cjs
node test-task-tracker.cjs
node test-history-ui.cjs
```

第二档用 Playwright 驱动本机 Chrome，验证提取器与并发 UI，需先安装依赖：

```sh
npm install
npm run test:browser
```

真实抖音与微信文章需用用户的实际页面验收。已验证模拟网页的作者/正文提取、完整图集顺序与嵌套分享封面排除；网站结构、风控和视频直链过期可能需要重试或更新适配。

## 多平台后端适配

采集请求在服务端先做校验：平台是否受支持、作者信息、规范化后的来源地址与平台 CDN 域名；消费站维持登录鉴权、数据库去重和个人关系/排序。通过校验后再复用既有的公共采集与发布入口。抖音走视频下载链路（可直接接收浏览器提供的视频信息）；微信走文章采集与图集处理链路。浏览器只传 JSON 元数据和媒体 URL，不本地下载再上传。未知平台、任意外站源地址、blob 视频地址及不支持的媒体 CDN 会被拒绝。

## 多任务与完成通知（1.4.0）

采集按钮只在提交请求期间禁用，收到后台接受结果后即可继续采集其他笔记；后台媒体处理仍按资源限制排队。同一素材的进行中提交会合并跟踪，避免重复通知。

`task-tracker.js` 在扩展后台保存任务、检查状态、更新工具栏进行中数量。来源页面显示多任务面板，扩展弹窗显示最近任务；完成或失败后发送系统通知，点击通知打开消费站更新页。状态同步短暂断网时自动重试，切换账号时等待原账号重新连接，不用其他账号查询该任务。

正常运行时每约 3 秒检查状态，另以 30 秒 Chrome alarm 兜底并在后台启动时重建。浏览器完全退出、设备休眠或系统限制可能延后检查；系统通知被禁止时，页面及弹窗仍保留结果。后端任务不会因关闭来源标签页而取消。

头像修复：小红书 author.avatar/avatarUrl 经白名单校验和 HTTPS 规范化后完整保留。已有笔记复用时也补全消费者和素材主数据中缺失或默认头像，保留已有有效头像。

后台生命周期依据 [Chrome alarms 文档](https://developer.chrome.com/docs/extensions/reference/api/alarms)；系统通知使用 [Chrome Notifications API](https://developer.chrome.com/docs/extensions/develop/ui/notify-users)。

## 抖音个人主页弹层修复（1.4.1）

优先匹配当前作品的作者卡片，支持仅头像链接中的博主名称及 React 动态详情数据。
避免将评论用户、登录用户或主页路由直接用作作品作者。已在用户提供的个人主页 modal_id 链接验证作者与正文提取；未在该作品上触发真实素材下载或发布。

## 通知网站入口（1.4.2）

采集提示包含可点击的 Closet4U 网站链接，系统通知显示网站地址并支持点击打开。
登录失效时引导登录并保持网站页面打开后重试；已提交任务在原账号恢复登录后自动继续查询。

## 收起采集提示（1.4.3）

点击采集任务提示框的非链接区域即可收起，也支持 Escape；收起后后台继续采集和系统通知，普通任务状态刷新不会重新展开。下次采集会重新显示提示。

## 抖音推荐视频流（1.4.5）

支持 `https://www.douyin.com/?recommend=1`，从当前可见并播放的视频卡片、React 数据或本卡片作品链接确定 ID。提交标准 `/video/ID` 链接、博主和正文；有直链时一并发送，无直链时后端继续尝试解析。
切换视频后重新读取，排除隐藏预加载和旧 hover 标记。无法确定归属时提示播放后重试或打开详情，不取全局列表第一条。
模拟 Chrome 场景与后端适配检查通过；新浏览器真实推荐页出现验证码，本轮未完成登录态推荐流端到端下载验收。

## 最近任务与历史记录（1.4.6）

采集提示及扩展配置页按创建时间倒序显示最近 5 条任务，其余保留在“历史记录”中，展开后继续显示状态与原有操作。折叠状态在刷新任务状态时保留；0–5 条不显示空历史入口。此改动不删除记录，也取消原先的已结束任务数量裁剪；Chrome 原有存储配额与扩展权限不变。过去版本已移除的记录无法恢复。底部 Closet4U 链接打开已连接消费站的 `/updates` 探索页；旧默认站点页脚改用已验证的生产入口 `https://danime.dawoai.com/closet/updates`（旧域名只读核验返回 403）。自定义站点和登录重试链接仍保留原地址及路径。

本次仅生成本地测试包，不覆盖站点当前下载包，不上传 Chrome 商店。已安装开发版可按既有流程替换目录后手动刷新扩展；本轮不会自动安装或更改浏览器权限。
